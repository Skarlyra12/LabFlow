# LabFlow

Sistema acadêmico para gestão de laboratórios universitários.

## Tecnologias

- Next.js
- TypeScript
- Tailwind CSS

## Estrutura atual

```text
Front-end
↓
API Routes
↓
Dados temporários
```

## Estrutura futura

```text
Front-end
↓
API Routes
↓
Prisma
↓
MySQL
```

## Executar projeto

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.
